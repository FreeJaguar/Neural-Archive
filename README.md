# Neural Archive

אתר בעברית ובכיוון RTL לגלוי כלי AI חינמיים, חדשות ומחקר, כולל הסבר על מסלולים חינמיים ומגבלותיהם.

**האתר הראשי:** https://neural-archive-two.vercel.app/

## האתר

- `index.html` — דף הבית הציבורי בעיצוב Cinematic 2.5D שאושר.
- `design.html` — אותה תצוגת עיצוב כעמוד Preview לצורכי בדיקה (`noindex`).
- `design.css`, `compact-hero.css`, `compact-sections.css`, `hero-motion.css` — עיצוב, פריסה רספונסיבית ואנימציה.
- `design.js`, `hero-motion.js` — ניווט, חיפוש וסינון, מועדפים, חלוניות פרטים ואנימציות מונגשות.
- `assets/cinematic-*.webp` — רקע התמונה ושכבות הקובייה והמסכים הצפים.
- `data.js` — **מקור הנתונים היחיד** של הכלים והקטגוריות, משותף לכל התצוגות.

קובצי `app.js`, `styles.css` ו-`news-promo.css` מהאתר הישן נשמרים לשחזור אך אינם נטענים בדף הבית החדש.

### חדשות AI

- `/news` — חדשות שאושרו לפרסום.
- `/api/news` — API ציבורי לחדשות המאושרות בלבד; דף הבית מציג ממנו עדכונים.
- `/api/telegram` — בוט עריכה פרטי לאישור, דחייה ועריכת ידיעות.
- Supabase מאחסן את הידיעות. הרשאות השירות נשארות בשרת, ולא בדפדפן.
- איסוף וסינון באמצעות GitHub Actions מוסברים במסמכי `docs/`.

### בדיקות

בדיקות הטקסט, המבנה והקישורים:

```bash
node --test tests/design-preview.test.mjs tests/homepage-release.test.mjs
```

בדיקות ממשק Chromium למסכים שונים, חיפוש, חלוניות פרטים, נגישות ואנימציות מתבצעות ב-GitHub Actions דרך `tests/design-visual-smoke.mjs`.

לקטלוג הסטטי אין שלב build. ניתן להפעיל שרת מקומי מתוך תיקיית הפרויקט:

```bash
python -m http.server 4173
```

לידיעות החיות דרושים משתני הסביבה של Vercel וסביבת Supabase מוגדרת; אין לשים מפתחות סודיים בקבצי הפרויקט או במערכת הלקוח.

הערה: תמחור, מגבלות שימוש וזמינות כלים עשויים להשתנות; כל טענה נבדקת מול מקור רשמי לפני עדכון.
