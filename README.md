# מפת הכלים החינמיים

קטלוג סטטי בעברית ובכיוון RTL של כלים דיגיטליים עם מסלול חינמי מתמשך ומקורות רשמיים.

האתר אינו דורש תהליך build: פותחים את `index.html` או מפרסמים את תיקיית השורש כפלט סטטי.

## מבנה

- `data.js` — רשומות הכלים, המגבלות והמקורות.
- `app.js` — חיפוש, סינון, כרטיסים ופאנל פרטים.
- `styles.css` — עיצוב רספונסיבי ונגיש.

כל טענת מחיר או מכסה צריכה להיבדק מחדש מול מקור רשמי לפני עדכון הרשומה ותאריך האימות.
