# מפת הכלים החינמיים

קטלוג סטטי בעברית ובכיוון RTL של 90 כלים דיגיטליים עם מסלול חינמי מתמשך ומקורות רשמיים.

האתר החי: https://neural-archive-two.vercel.app/

קטלוג הכלים עצמו אינו דורש תהליך build וניתן לפתוח את `index.html` באופן סטטי. תוסף חדשות ה-AI משתמש בפונקציות Serverless של Vercel ובמסד נתונים Supabase נפרד, ולכן הוא דורש פריסה פעילה והגדרת משתני סביבה.

## מבנה

- `data.js` — רשומות הכלים הפעילים, המגבלות, המקורות ורשימת המעקב.
- `app.js` — חיפוש, סינון, מיון, עדכונים לפי יום, כרטיסים ופאנל פרטים.
- `styles.css` — עיצוב רספונסיבי ונגיש.

כל טענת מחיר או מכסה צריכה להיבדק מחדש מול מקור רשמי לפני עדכון הרשומה ותאריך האימות.

## חדשות AI - שלב פיתוח

- עמוד החדשות: `/news` (מציג ידיעות שאושרו בלבד).
- ניהול ידיעות: בוט Telegram פרטי עם פקודות `/add`, `/pending`, `/edit` וכפתורי אישור ודחייה.
- אחסון: Supabase מאובטח דרך השרת, ללא גישה ישירה מהדפדפן.
- הוראות התקנה: `docs/telegram-news-moderation.md`.
- אין בשלב זה איסוף אוטומטי מערוצי Telegram או סיכום באמצעות AI.
